Do's and Don'ts

Do

  • Use only Helvetica/Arial — the template font — at every size and weight.
  • Keep the exact taupe/black/white palette and the KNOW/DO/BECOME triad.
  • Always pair each learning-outcome colour with its text label so it reads in B&W.
  • Preserve the calm, one-idea-per-block layout with generous margins.
  • Keep surfaces flat: solid fills and hairline borders.

Don't

  • Don't swap, mix, or add typefaces — no script, handwriting, or trendy display fonts.
  • Don't recolour or restyle away from the sampled template palette.
  • Don't rely on colour alone to convey meaning (must survive a B&W copier).
  • Don't crowd the page or stack blocks without breathing room.
  • Don't add drop shadows, gradients, or corners beyond 2px.
  • Don't drift from the template layout — same components, same order.
